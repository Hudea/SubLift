# 10105 建立 Context Inspector 与 Video 模式 — 执行计划

> 状态：done（2026-08-12）。计划正文；验收证据写入 `docs/phases/phase10.json` 的 10105.evidence。

## 目标

实现可开关、可调整的 Inspector 容器与确定的模式切换，把 metadata 从主内容归位到 Video Inspector；Region/Extraction/Subtitle 面板保持明确内部占位。

## 验收标准（来自 phase10.json）

1. Inspector 宽 280–360pt、可关闭并释放内容面积；用户关闭后状态转换不强制重新打开。
2. Video 模式只展示 VideoMetadataLoader 的文件名、分辨率、时长、编码、大小、容器与真实预览兼容性。
3. Video/Region/Extraction/Subtitle 模式切换遵守状态规范；暂未实现的面板使用明确内部占位而非用户可见假数据。
4. 原 metadataBar 不再重复占据视频工作区；窄窗口关闭 Inspector 后布局仍通过 V08。
5. mode/resize tests、swift test 与 V03 实际截图写入 evidence。

- VideoInspectorPresentation 是纯函数（无状态）。
