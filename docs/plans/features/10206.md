# 10206 实现字幕区域编辑模式 — 执行计划

> 状态：in-progress（2026-08-12 启动）。计划正文；验收证据写入 `docs/phases/phase10.json` 的 10206.evidence。

## 目标

把候选选择和几何信息从常驻主内容重组为显式 Region Editing + Region Inspector，统一 overlay 视觉语义。

## 验收标准（来自 phase10.json）

1. 候选框只在 regionEditing 可见；正常模式仅显示最终 merged region，且不显示随机色、工程编号或常驻坐标。
2. 未选中/hover/selected/merged 使用 secondary/Accent 语义并带文字或控件状态，不依赖颜色。
3. Region Inspector 支持候选多选、重检当前帧、合并摘要和可折叠高级几何；检测/空/失败均有恢复文案。
4. 现有 source-frame 坐标、全宽合并、subtitle profile 和 Worker ROI 数据保持不变，既有 RegionGeometry/PreviewLayout 测试通过。
5. 新增 Region mode/keyboard/VoiceOver tests、swift test 与 V04 实际截图写入 evidence。

## 测试先行顺序（TDD）

1. `RegionEditingTests`：
   - RegionBoxVisual.style 派生（selected/hover/merged 状态 → 视觉配置，不依赖颜色可辨）
   - overlay 可见性（候选框仅 regionEditing）
   - 高级几何文本（X/Y/宽高/置信度真实字段）
   - 合并摘要文本
2. 实现后专项通过 → 既有 RegionGeometryTests/PreviewLayoutTests 回归 → 完整 swift test。

## 状态与数据所有权

- RegionSelectionModel 保持候选/选择/合并/IPC 数据所有权（不改 source-frame 坐标、全宽合并、subtitle profile、Worker ROI）。
- WorkspaceModel 的 regionEditing 状态驱动 overlay 可见性与 Inspector 模式。
- 视觉语义（RegionBoxVisual）为纯函数。

## UI 与 Core 职责边界

- Core：RegionSelectionModel（既有）；视觉状态派生为纯逻辑。
- UI：overlay 渲染、Inspector 列表与折叠区；不改变检测算法或 IPC 数据。
