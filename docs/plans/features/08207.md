## Snapshot/Schema/恢复合同（冻结）

### BatchQueueSnapshot（versioned Codable）

- `schemaVersion: Int`（=1）、`savedAt: Date`、`tasks: [BatchTask]`、`runningTaskID: UUID?`、`status: BatchQueueStatus`。
- 保存任务摘要/顺序/配置/输出/状态/计数/错误/时间；**不保存**帧、字幕全文、无限日志、run token（BatchTask CodingKeys 已排除）。

### BatchQueueRepository（BatchQueuePersisting 生产实现）

- 默认路径：Application Support/SubLift/batch-queue-v1.json（`FileManager.urls(.applicationSupportDirectory)`）；测试注入临时目录。
- 保存：snapshot → 同目录临时文件（`.batch-queue-v1.json.tmp-UUID`）→ 原子替换；失败原文件字节不变、临时清理。
- 恢复（load）：
  - 文件不存在 → `.empty`；
  - 解析失败/结构损坏 → `BatchQueueRepositoryError.corrupted`（**不覆盖原文件**）；
  - `schemaVersion != 1` → `.unknownSchemaVersion(Int)`（不覆盖原文件）；
  - 有效：preparing/extracting/exporting → **interrupted**；队列 **running → paused**（idle/paused 保持原状态）；
    **不创建 Worker**（纯状态转换）。
- 显式新建：`reset()` 删除文件（错误后调用方选择）。
- 节流：progress 不触发保存（Scheduler 只在结构/状态变化时 persist——08205 既有策略）；repository.save 始终原子全量。
