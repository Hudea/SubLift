## 产品合同（10415.01 冻结）

### 快速设置栏（QuickExtractionSettingsBar）

- **位置**：`ExtractionProgressView` 下方、videoPane 底部 Spacer 之前（空白工作区顶部）。
- **高度**：约 52–64pt（两行紧凑布局：标题行 + 控件行），不使用大卡片、渐变或新配色。
- **常规宽度显示**：
  - 标题「提取设置」（caption semibold secondary）；
  - OCR 引擎 Popup（`EngineCapability.visibleEngines` + `normalizedSelection` 归一化，Mock 仅开发者模式）；
  - 「快速／平衡／精细」采样分段控件（`SamplingQuality.allCases`）；
  - 必要时显示「配置已更改，重新提取后生效」（图标 + 文字，不依赖颜色）；
  - 仅「已有最终结果且配置变化」时显示「重新提取」按钮。
- **960pt 紧凑**：`ViewThatFits` 将采样分段控件降级为 Popup，无横向溢出。
- **偏好真源**：与 Settings 共用 `default_engine` / `sampling_quality` / `developer_mode` @AppStorage；不把 UserDefaults 复制进 WorkspaceModel。
- **运行中**（starting/processing/finalizing）：控件 disabled 但值可读；当前任务使用启动时快照，不受运行途中偏好变化影响。
- **配置变化不自动启动提取**。
- 不显示 Automatic、Whisper、ETA、平均置信度或模型下载入口。

### 配置快照（ExtractionConfiguration，Core）

```swift
struct ExtractionConfiguration: Equatable {
    let engine: OcrEngineName
    let quality: SamplingQuality
}
```

- `activeExtractionConfiguration`：`startExtraction` 时设置（归一化后）；成功（final entries 落地）/失败/取消后清空。
- `finalExtractionConfiguration`：只在 `handleExtractionFinalEntries` 成功落地时由 active 快照更新。
- 重新提取失败/取消并恢复旧字幕（retainedFinalEntries）时，保持旧 final 快照不变。
- 打开新视频（`openVideo`）时清空两种快照。
- 偏好（@AppStorage）与 `finalExtractionConfiguration` 不同 → 待生效状态（pending notice + 重新提取按钮）。

### 统一提取请求（requestExtraction）

- Toolbar「提取字幕」与设置栏「重新提取」走同一 `requestExtraction()`。
- 先执行 Mock 归一化（`EngineCapability.normalizedSelection`，持久化偏好同步回落）。
- `workspace.hasFinalEntries == true` 时弹「替换现有字幕」确认（sheet/alert，Cancel 为安全默认）。
- 用户确认后才调用 `workspace.startExtraction(engine:quality:)`；取消不得清空/修改字幕与配置。
- View 不复制 Workspace 状态机。

### Extraction Inspector 去重

- 删除引擎/采样可编辑 RadioGroup（Settings 与快速设置栏是仅有的偏好编辑入口）。
- 只读展示规则：active 配置优先 → final 配置其次 → 偏好配置最后。
- runtime 与状态继续显示真实数据。

## 测试先行顺序（10415.02）

1. `ExtractionConfiguration` engine/quality 相等性。
2. `activeExtractionConfiguration` 启动时设置；成功/失败/取消后清空。
3. `finalExtractionConfiguration` 只在成功完成时更新。
4. 重提取失败/取消恢复旧字幕时旧 final 快照保留。
5. 打开新视频时两种快照清空。
6. 偏好与 final 配置不同才显示待生效状态（pending/reextract 派生）。
7. 运行中快速设置不可编辑（展示层禁用派生）。
8. 非开发模式下 Mock 选择被归一化（含 requestExtraction 路径）。
9. 有最终结果时提取请求需确认；无最终结果时直接执行（展示层派生）。
10. Inspector 展示运行快照而非已改变偏好（展示层优先级规则）。
11. 核心状态生命周期测试不得用源码字符串断言替代。
