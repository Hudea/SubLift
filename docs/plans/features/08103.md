## 扫描合同（冻结）

### BatchInputScanner（可注入纯扫描服务）

- 输入：URL 列表（文件或目录）+ `recursive: Bool` + 队列已有 URL（去重）。
- 文件输入：经 `VideoImportPolicy.validate`（复用真源）；hidden/package/symlink 不进入扫描；标准化 URL 去重。
- 目录输入：默认非递归（仅直接子项）；显式递归后按**相对路径稳定排序**枚举。
- 拒绝原因（结构化）：`unsupportedFormat(ext)` / `mkvRequiresFfmpeg` / `unreadable` / `duplicate`（本批或已有队列）/ `emptyDirectory`。
- 隐藏项、package、symlink **静默排除**（不进 accepted，也不计入拒绝摘要）。
- 扫描不启动 metadata、Worker 或 OCR；结果一次性返回摘要（不逐文件同步 UI）。
- MKV 缺 ffmpeg：通过注入 `VideoImportPolicy(ffmpegAvailable:)` 复现。

### 类型

```swift
struct BatchScanRejection: Equatable { url, reason }
enum BatchInputRejectionReason: Equatable { unsupportedFormat(String), mkvRequiresFfmpeg, unreadable, duplicate, emptyDirectory }
struct BatchScanSummary: Equatable { accepted: [URL], rejected: [BatchScanRejection] }
struct BatchInputScanner { policy; existingURLs; func scan(inputs:[URL], recursive: Bool) -> BatchScanSummary }
```
