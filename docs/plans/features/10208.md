# 10208 实现安全的 Processing 体验 — 执行计划

> 状态：in-progress（2026-08-12 启动）。计划正文；验收证据写入 `docs/phases/phase10.json` 的 10208.evidence。

## 目标

把真实提取状态、进度、倍速、runtime 和停止动作投影到工作区，强制 Live Transcript 在最终结果前只读。

## 验收标准（来自 phase10.json）

1. starting/processing/finalizing 保持 Video/Transcript 工作区，不跳 Loading page；Toolbar 主动作是 Stop。
2. 进度只显示现有 status 的 pct/frame counts、processingRate 与 runtimeIdentity；不可可靠推导的 ETA/平均置信度不显示。
3. Live Transcript 可选择、seek、搜索，但文本修改、Split、Merge、Export 及 Subtitle Inspector mutation 全部禁用并有只读辅助说明。
4. Stop 立即失效当前 job，迟到 progress/push/final entries 被忽略；取消、连接错误和重试后第二任务可正常开始。
5. 提取 lifecycle/read-only/late-event tests、既有 PipelineClient/SubtitleExtractor tests、swift test 与 V05 截图写入 evidence。

## 测试先行顺序（TDD）

1. ExtractionProgressPresentationTests：进度文本真实计数、无 ETA/假置信度、rate 仅在有时显示、runtime 显示。
2. TranscriptReadOnlyNoticeTests：processing 有只读说明、review 无。
3. ExtractionInspectorPresentationTests：engine/quality/runtime 行来自真实配置。
4. 实现后专项通过 → 既有 PipelineClient/SubtitleExtractor 回归 → 完整 swift test。
