## 目标

修复 Phase 10 独立审计发现的安全降级、响应式布局、真实快捷键、搜索编号和视觉细节问题，并通过 TDD、代码复核、真实 macOS UI 回归和项目完整验证重新关闭 Phase 10。

## 执行顺序

1. 先补失败测试，分别锁定隐藏 Mock 引擎、Inspector 挤压 Transcript、Esc 退出区域编辑、搜索结果原始编号等行为。
2. 并行修复互不重叠的 Settings/引擎策略、Workspace 布局与快捷键、Transcript/Timeline/Welcome 视觉语义。
3. 主 Agent 统一审查差异，补齐 composition root 的运行前保护，执行修改复核。
4. 运行定向测试、完整 Swift 测试、标准项目门，并用真实 App 做关键路径和窗口尺寸回归。
5. 将命令、结果、截图、残余限制写入 evidence，同步进度真源；所有门通过后才重新关闭 Phase 10。

## 验收重点

- 关闭开发者模式后，持久化的 Mock 选择被归一为可见生产引擎，Picker 不空白，提取入口也不能继续启动 Mock。
- 在支持双栏的窗口宽度内，打开/关闭 Inspector、缩放窗口和反复拖动分隔线后 Transcript 均不低于设计最小宽度且无横向溢出。
- Region Editing 中真实按下 Esc 可退出编辑；Space 播放快捷键保持有效，测试覆盖实际命令路由而非只验证字符串目录。
- Transcript 搜索结果保留源字幕序号，不因过滤重新编号。
- Welcome 主层级保持聚合；Timeline 全范围文本在紧凑宽度不换行；关键 Toolbar 状态操作具备清晰可见语义。
- 定向测试、完整 `swift test`、`./scripts/verify-standard.sh`、`./init.sh`、JSON/链接/diff 检查和真实 UI 冒烟均有可复核证据。
