# 10207 重构 Transcript Panel 与上下文命令 — 执行计划

> 状态：done（2026-08-12）。计划正文；验收证据写入 `docs/phases/phase10.json` 的 10207.evidence。

## 目标

将字幕列表重组为标准 Transcript Panel（搜索、行层级、selection/current、上下文命令）。

## 验收标准（来自 phase10.json）

1. Header 显示真实条数与 Search Field；搜索只过滤/定位显示，不改变 entries 顺序或导出内容，清空后恢复当前播放定位。
2. TranscriptRow 使用序号、等宽 start/end、正文和必要的低置信警告；不使用逐行 Card 或永久 confidence 数值。
3. selection 与 current playback 分别表达；单击 seek、Review 双击编辑；空/搜索无结果/长文本状态可用。
4. Edit/Split/Merge/Copy/Reveal 命令进入右键与菜单，复用 Workspace availability；边界条目正确禁用 Merge。
5. 搜索/选择/命令/长文本 XCTest、swift test 和 Ready/Review 行状态截图写入 evidence。
