## Runner 事件合同（冻结）

### BatchExtractionRunner（BatchTaskRunning 生产实现）

- 每任务**独占 PipelineClient/Worker/socket**：run 内创建，defer stop()（teardown 关闭 socket）；
  Workspace 与 Batch 不共享可变 SubtitleExtractor（Batch 独立 IPC 生命周期）。
- 事件映射（Scheduler 不解析 UDS）：
  - client.start → `.preparing`（starting 阶段）
  - requestStreaming onProgress（非 finalizing）→ `.extracting` + pct
  - onProgress stage=="finalizing" → `.exporting`
  - final entries → SrtFormatter.format → AtomicSrtWriter.write（**成功原子写出后才 completed**）
  - runtime：`lastWorkerChoice.runtime.rawValue` 摘要进入 outcome
  - 错误 → `.failed(message)`；Task 取消 → `.cancelled`（teardown 关 socket，无迟到事件）
- 隐藏 Mock 启动前再次归一化（`EngineCapability.normalizedSelection`，non-dev → vision）。
- 写出后释放完整 entries：outcome 只保留 entryCount/outputURL/runtimeIdentity 摘要。
- `BatchIPCClient` 协议（start/stop/lastWorkerChoice/requestBatchStreaming）：
  PipelineClient 最小包装 conform（requestBatchStreaming），测试注入 Fake。

### BatchRunOutcome.completed 扩展

`completed(entryCount:outputURL:runtimeIdentity:)`（runtime 摘要；scheduler 存入 BatchTaskResult.runtimeIdentity）。
