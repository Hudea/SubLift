## 已冻结关键决策

1. Task Center 使用独立 `BatchQueueModel`，不扩张 `WorkspaceModel` 为多任务真源。
2. Phase 8 固定单并发；暂停是“完成当前任务后暂停”，不挂起 Worker。
3. 文件夹默认不递归，不跟随软链接，复用 `VideoImportPolicy`，扫描阶段不启动 OCR。
4. 配置入队时复制，waiting 可显式修改，preparing 后锁定；Settings 改动不追溯。
5. 批量区域固定 Worker 默认底部区域；逐文件区域与校对留在 Workspace。
6. 默认 sidecar SRT；冲突默认跳过，也可自动重命名或明确确认替换。
7. SRT 临时写入后原子移动；completed 后不长期保存完整 entries。
8. 队列以版本化 JSON 恢复；活动任务恢复为 interrupted，启动后不自动续跑。
9. 不新增数据库、依赖、Worker/IPC、算法、并行 OCR、分发或新格式。
