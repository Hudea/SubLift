## 路径/冲突/原子写入合同（冻结）

### BatchOutputPlanner（纯路径规划）

- **sidecar（默认，outputRoot 为 nil）**：`source.deletingPathExtension().appendingPathExtension("srt")`（同目录同 basename）。
- **公共输出根**：文件夹输入保持相对目录（相对 sourceRoot）；独立文件用 basename。
- **路径逃逸保护**：目标标准化后必须仍在公共 output root 内；异常相对路径（`..` 等）fail-closed（返回错误）。
- **同批目标碰撞**：`planAll(sources:)` 检测重复目标 → fail-closed。
- **冲突策略**（目标已存在时）：
  - `skip`（默认）：conflict = `.skipped(existingURL)`；
  - `rename`：首个稳定可用 `name (N).srt`（(1) 被占则 (2)…）；
  - `replace`：conflict = `.replaced(existingURL)`（必须携带已确认策略——replace 为显式确认结果）。

```swift
enum BatchOutputConflictPolicy: String, Codable, Sendable { case skip, rename, replace }
enum BatchOutputConflict: Equatable { case none, skipped(existingURL: URL), renamed(from: URL, to: URL), replaced(existingURL: URL) }
struct BatchOutputPlan: Equatable { targetURL: URL; conflict: BatchOutputConflict }
enum BatchOutputPlannerError: Error { case targetOutsideRoot, unwritableDirectory, duplicateTarget }
struct BatchOutputPlanner { outputRoot: URL?; conflictPolicy: BatchOutputConflictPolicy
  func plan(source: URL, sourceRoot: URL?) -> BatchOutputPlan
  func planAll(sources: [URL], sourceRoot: URL?) throws -> [BatchOutputPlan] }
```

### AtomicSrtWriter（同卷原子写入）

- 目标同目录临时文件（`.basename.tmp-UUID`）→ 写入 → `FileManager.replaceItemAt` 原子移动/替换。
- 失败：defer 清理临时文件；已有目标字节不变。
- 不通过 shell/glob/未验证字符串拼接生成路径。
