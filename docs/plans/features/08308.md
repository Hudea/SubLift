# 08308 实现原生 Task Center Window — 执行计划

> 状态：in-progress（2026-08-12 启动）。验收证据写入 `docs/phases/phase8.json` 的 08308.evidence。

## Scene/布局/命令合同（冻结）

### 所有权

- App scene 层持有**唯一** `BatchQueueModel`（ObservableObject，包装 Scheduler + Repository）。
- Task Center 为**独立 WindowGroup**（⌘⇧T 打开）；Workspace 只增加显示入口（菜单），不增加永久 Sidebar；两个组合根状态互不清空。
- 启动恢复：model init 时 repository.load()——成功 → scheduler(initialState)；损坏/未知版本 → 可展示错误 + 空队列（不覆盖原文件）。

### 布局（原生 macOS）

- 主区：`Table`（文件/时长/引擎/状态/进度/输出/添加时间），列优先级：文件（弹性）> 状态 > 进度 > 引擎 > 时长 > 输出 > 添加时间；长文件名/路径安全截断（lineLimit + truncationMode）。
- 选中详情：源/配置（engine+quality）/runtime/error/output/task ID（等宽）。
- Toolbar：添加文件/添加文件夹/开始/暂停/恢复/停止/取消/重试——按 availability 启用。
- Summary 汇总条：总数/等待/活动/完成/失败/取消/跳过。
- 不显示 Whisper、Automatic、虚假 ETA/平均置信度、模型下载。

### 命令 availability（纯逻辑，TaskCenterPresentation）

- 队列级：`canStart`（有 waiting 且未 running）/`canPauseAfterCurrent`（running）/`canResume`（paused）/`canStop`（running）。
- 任务级：复用 `BatchTaskCommandAvailability`（canCancel/canRetry/canRemove/canReplaceConfiguration）。
- 状态显示名/进度文本/时长格式投影真实字段。
