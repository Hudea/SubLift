# 10209 实现 Review、Subtitle Inspector 与 Export — 执行计划

> 状态：in-progress（2026-08-12 启动）。计划正文；验收证据写入 `docs/phases/phase10.json` 的 10209.evidence。

## 目标

final entries 原子切换 Review；Subtitle Inspector 只显示真实字段；导出只在 Review 且仅 SRT。

## 验收标准（来自 phase10.json）

1. final entries 原子切换为 Review（不经过 processing 的渐变）。
2. Subtitle Inspector 只显示真实字段（索引、时间、文本、低置信警告），不提供假字段。
3. 导出只在 Review 状态；只导出 SRT；processing 与无 final result 时不可导出。
4. Review 阶段允许编辑/拆分/合并（canSplit/canMerge 语义为"拆分当前选中"）。
5. Review/export XCTest、swift test 与 V06 实际截图写入 evidence。

4. 实现后专项通过 → 完整 swift test。
