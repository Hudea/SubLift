## 交互合同（冻结）

### 统一导入（文件/文件夹/drop 同一 scanner）

- `BatchQueueModel.importInputs(_ urls: [URL])`：全部走 `BatchInputScanner`（注入，默认 `VideoImportPolicy()`）——
  accepted → `BatchTask.make`（默认配置，make 内归一化）→ `addTasks`；
  rejected 逐项原因 → `@Published lastScanSummary: BatchScanSummary?`（B02 摘要：接受/跳过/拒绝 + 逐项原因）。
- 不自动开始（B02）；文件夹输入 scanner 默认不递归（08309 不增加递归开关 UI）。

### 投影（搜索/筛选只改变投影）

- `searchText` + `statusFilter`（all/waiting/running/completed/failed/cancelled/skipped）→ `filteredTasks` 纯投影；
  Table 显示 filteredTasks；实际队列操作仍作用于真实 task id。

### waiting 操作（availability 唯一真源）

- 多选删除：仅 waiting（`BatchTaskCommandAvailability.canRemove`）；删除/取消危险操作先确认（alert destructive）。
- 显式改配置：仅 waiting（canReplaceConfiguration）；菜单/详情内选择 engine/quality。
- 重排：仅 waiting（canReorder）；选中上移/下移按钮（保留槽位语义复用 scheduler.reorder）。

### 输出冲突集中确认（开始前）

- start 前对全部 waiting 任务用 `BatchOutputPlanner`（sidecar 默认 + skip 策略）预规划：
  目标已存在 → 集中确认 alert（列出冲突文件，destructive"替换现有字幕？"）；
  确认 → 以 replace 策略重规划并写入 `task.outputURL` 后 start；取消 → 不启动、不删除/覆盖任何输出。

### Finder 与错误

- "在 Finder 中显示"：源/输出存在 → `NSWorkspace.activateFileViewerSelecting`；不存在 → 错误 alert（不静默）。

### B08/B09

- B08：960×600 紧凑（COMPACT fixture）+ 搜索/筛选/多选元素无裁切。
- B09：窗口级 `NSAppearance(named: .darkAqua)`（fixture 注入，不切系统）+ 非默认 Accent
  （`SUBLIFT_EVIDENCE_ACCENT=1` → `TaskCenterView.tint(.orange)`，DEBUG-only）；
